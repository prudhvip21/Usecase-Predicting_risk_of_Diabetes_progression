# Predicting Risk of Diabetes

Predict the onset of diabetes from diagnostic measurements.

## Approach

- Data quality checks and imputation in a pipeline
- KNN, Logistic Regression, SVM, Random Forest, AdaBoost and Gradient Boosting

## Start here

[Diabetes-refined.ipynb](Diabetes-refined.ipynb)

## Data

Pima Indians diabetes dataset from the National Institute of Diabetes and Digestive and Kidney Diseases, included.
